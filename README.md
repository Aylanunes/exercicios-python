# 🐍 Exercícios em Python

Coleção de exercícios práticos e algoritmos desenvolvidos em **Python 3**.

## 📂 Arquivos Inclusos

* **`jokenpo.py`**: Implementação interativa do clássico jogo Pedra, Papel e Tesoura (Jokenpô).
* **`media.py`**: Cálculo de médias e estruturas condicionais para notas/aprovação.
* **`casa.py`**: Algoritmo com tomada de decisão.
* **`Desafio2.py`**: Resolução de desafio lógico.
* **`Exercicios.py`**: Práticas de sintaxe e comandos fundamentais da linguagem.
* **`python.py` / `teste.py`**: Testes rápidos e validações de lógica.

## 🛠️ Como executar:
```bash
python nome_do_arquivo.py
```
